Desktop: WASD / arrows move, Q/E down/up, Shift faster, drag to look, wheel = lens FOV, R reset view
L toggle spill / N next demo scene / Space play-pause / H hide UI
Curvature: 0 = flat. GLB screens are auto-detected as flat or curved. Size grows from the bottom edge; aspect follows the video.
Seat kit: seat and armrest are separate GLBs, origin on the floor, front facing -Z, meters. The repo kit (assets/seat_kit) loads by default.
VR: left stick move, right stick turn (smooth by default, snap in the menu) + up/down, A/X reset to seat, trigger toggle spill, grip next scene. Y opens the menu on your left controller (L-stick select, R-stick adjust, A/trigger confirm). This desktop panel hides automatically in VR.
GLB tip: name your screen mesh Screen and add an empty called Viewpoint at seated eye height. Units in meters.

Light Spill Lab

Prototype of the screen light spill system for the Quest 3 VR Cinema project. The screen image is downsampled, blurred, smoothed over time and used as a set of area light zones that tint the room.
